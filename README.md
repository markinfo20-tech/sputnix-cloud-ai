# SPUTNIX CLOUD AI — V2

Обновлённый Streamlit-интерфейс. В нём есть:
- сворачиваемая левая панель настроек;
- поддержка отдельных изображений и ZIP-архивов;
- отдельная кнопка запуска анализа (загрузка не запускает ИИ автоматически);
- понятный прогресс обработки;
- просмотр исходника, маски и наложения;
- выгрузка полного ZIP с оригиналами, масками, наложениями и CSV-отчётом;
- ранняя проверка лимита памяти, чтобы не оставлять пользователя на бесконечной загрузке.

## Деплой
Загрузите в корень GitHub-репозитория `app.py`, `cloud_core.py`, `requirements.txt`, `ATTRIBUTION.txt` и папку `.streamlit/`.
В Streamlit выберите `app.py` как Main file path.

## Критически важное ограничение бесплатного Layero
Документация Layero указывает для Free 256 МБ RAM и предел 60 секунд на один запрос runtime. Файл весов CLIPSeg занимает около 603 МБ — это больше всего доступной памяти ещё до запуска PyTorch. Поэтому эта модель физически не подходит под бесплатный runtime Layero. V2 проверит лимит и покажет понятное предупреждение вместо бесконечной загрузки. Сам веб-интерфейс и ZIP-загрузка останутся доступны, но ИИ-анализ на таком тарифе не запустится.

Для настоящего инференса этой моделью нужен хост с существенно большим объёмом RAM (ориентировочно от 1,5 ГБ, это практическая оценка, а не гарантия).

## Процент облачности
Расчёт после сегментации: (число пикселей классов `thick cloud` + `thin cloud`) / общее число пикселей × 100. `Cloud shadow` отображается отдельно и в процент облачности не входит.

## Проверка
Локально проверено:
- `python -m py_compile app.py cloud_core.py` — синтаксис компилируется;
- `pytest -q` — 4 теста проходят;
- тесты проверяют точные проценты на искусственных масках с известным числом пикселей, чтение изображений из ZIP и состав выходного ZIP.

Это подтверждает математическую корректность процента по готовой маске и ZIP-процессинг, но НЕ подтверждает точность самой ИИ-сегментации на снимках Sputnix. Для неё нужна размеченная контрольная выборка снимков Sputnix. Модельная карточка приводит mIoU 0.6572 на тестовой части CloudSEN12+; это не гарантия такой же точности на данных Sputnix.

## Форматы и ограничения загрузки
Поддерживаются PNG, JPG/JPEG, TIFF и WEBP; ZIP можно загрузить напрямую. Архив обрабатывается без распаковки на диск. Ограничение одного изображения — 60 МБ, суммарный распакованный объём ZIP — 250 МБ, до 200 изображений за загрузку. На многоканальном TIFF по умолчанию используются первые три канала; их соответствие RGB необходимо проверить для конкретного набора данных.
